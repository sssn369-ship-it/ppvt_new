# PPVT New - 취학전 아동 그림어휘력 검사

브라우저만으로 실행되는 20문항 그림어휘력 검사 웹앱입니다.

## 구성
- 4개 범주 × 5문항: 동물, 음식, 생활 사물, 기초 개념
- 문항당 그림 선택지 4개: 정답 1개 + 오답 3개
- 총점, 범주별 정답 수, 전체·평균 반응 시간 대시보드
- 문항별 반응 시간 및 정오답이 포함된 CSV 내보내기
- 그림 로드 오류 시 단어와 요청 그림파일명을 텍스트로 표시

## 실행
`index.html`을 브라우저로 열면 됩니다. 별도 설치나 서버가 필요하지 않습니다.

## 그림 파일
선택지 그림은 `img/` 폴더에서 찾습니다. 새로운 그림을 사용할 때는 `app.js`의 `assets` 항목에 한글 단어와 그림파일명을 추가해 주세요. 파일이 없으면 화면에 해당 파일명이 표시됩니다.

## 유의사항
본 도구는 교육 및 선별 목적의 예시 도구이며, 표준화된 임상·진단검사를 대체하지 않습니다.
